# ระบบเบิกพัสดุห้องยา
แผนกเภสัชกรรม โรงพยาบาลจุฬารัตน์ 9 แอร์พอร์ต

เว็บแอปไฟล์เดียว (`index.html`) สำหรับให้ผู้ช่วยเภสัชกรเบิกพัสดุ พร้อมติดตามสถานะ และให้แอดมินรวมใบเบิกส่งออกเป็น Excel

## ส่วนของระบบ
1. ฟอร์มเบิก 3 ขั้นตอน (รอบเบิก จันทร์/พฤหัส → รายการ → สรุป)
2. ติดตามสถานะ แก้ไข/ลบก่อนแอดมินรับ พร้อมประวัติ
3. จัดการการเบิก (แอดมิน): รับใบเบิก รวมใบเบิก ส่งออก Excel
4. ตั้งค่า (แอดมิน): พนักงาน พัสดุ หน่วยเบิก

## หมายเหตุการใช้งาน
- ออกแบบให้รันเป็น claude.ai Artifact ที่ใช้ `window.claude` (db, user, downloads) เปิดไฟล์นี้ตรงๆ นอก claude.ai ยังไม่ได้
- ข้อมูลพนักงาน/พัสดุ/หน่วย ต้องใส่ในฐานข้อมูลของ artifact (collections: staff, items, units) ไม่ได้เก็บไว้ใน repo นี้
